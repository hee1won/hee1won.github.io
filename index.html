20명+사용 중인 SM 담당자
월 300건+플랫폼으로 처리하는 요청
0원요청 분류 외부 API 비용
  • L1/L2 요청은 분류부터 완료 처리까지 사람 손 없이 자동 처리, 퇴근 후 들어오는 요청을 대신 봐주던 야간 인력이 필요 없어짐
  • ITSM 요청을 주기적으로 가져와 사내에 띄운 Qwen 모델로 L1(단순문의)/L2(데이터 조작)를 나누고, 할당부터 완료 처리까지 ITSM API로 자동 진행 (분류를 Qwen으로 옮기면서 분류 API 비용 0원)
  • 소스 수정이 필요한 L3 건은 읽기 전용 AI가 먼저 영향도를 보고, 사람이 승인해야 수정·커밋까지 가도록 승인 단계를 둠
  • UPDATE/DELETE/DDL은 자동 감지해서 승인 큐로 보내고, 승인 후에도 개발 DB에서만 실행되게 제한
  • 등록한 저장소에 질문할 수 있는 코드 챗봇 (응답 스트리밍, Claude/Qwen 선택)
  • LLM 없이 정적분석으로 CRUD 매트릭스, 자바 호출 관계도, 테이블 영향도, DB 스키마를 뽑아두고 챗봇이 먼저 참고하게 해서 토큰 사용량을 줄임
  • git/svn 연동, 빌드 → SFTP 업로드 → 재시작으로 이어지는 배포 기능
  • 역할별 권한, 접속 정보 암호화, 감사 로그, 사용자·프로젝트별 월 AI 사용 한도
